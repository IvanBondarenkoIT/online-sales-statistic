# Online Sales Statistic

Локальное окружение для работы с данными из Google Таблицы **«2026 Онлайн продажи / Online sales»**.

## Доступ к таблице

Таблица: [2026 Онлайн продажи / Online sales](https://docs.google.com/spreadsheets/d/1l60r1Rt83mALa2Hd3yViU8aOglSGlUPyeJQ39n084Xo/edit?gid=667824329#gid=667824329)

Данные подгружаются через **экспорт в CSV**. Это работает без API-ключей, если таблица открыта для просмотра по ссылке:

- Откройте таблицу → **Настройки доступа** (или «Поделиться»).
- Установите: **«Все, у кого есть ссылка»** → **«Просмотр»**.

После этого скрипт сможет скачать лист и сохранить его локально.

### Несколько вкладок (месяцы)

Если в таблице данные разнесены по вкладкам (например, месяц — одна вкладка), в `config.py` задаётся список **SHEET_GIDS**: один gid на вкладку. При загрузке данные со всех вкладок объединяются в один файл `data/online_sales.csv`; отчёты и аналитика по неделям учитывают все даты, в том числе из предыдущего месяца.

**Как узнать gid вкладки:** откройте нужную вкладку в браузере — в URL появится `#gid=ЧИСЛО`. Это число и есть gid. Добавьте его в список `SHEET_GIDS` в `config.py`.

## Локальное окружение (Python)

### 1. Создание виртуального окружения

```bash
cd D:\CursorProjects\online-sales-statistic
python -m venv .venv
```

### 2. Активация

**Windows (PowerShell):**
```powershell
.\.venv\Scripts\Activate.ps1
```

**Windows (cmd):**
```cmd
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Загрузка данных из таблицы

```bash
python fetch_sheet.py
```

Скрипт:

- скачивает все вкладки из списка `SHEET_GIDS` (config.py);
- объединяет данные в одну таблицу и сохраняет в `data/online_sales.csv`;
- выводит число листов, строк, столбцов и первые 5 строк.

Дальше можно использовать `data/online_sales.csv` в своих скриптах или в Excel.

### 5. Веб-отчёт для руководства

Перед первым запуском скопируйте `.env.example` в `.env` (или создайте `.env` с переменными `SECRET_KEY`, `ADMIN_USER`, `ADMIN_PASSWORD`). Для разработки: логин **admin**, пароль **admin**.

```bash
python app.py
```

Откройте в браузере: **http://127.0.0.1:5000** — откроется страница входа. После входа:

- **На дату** — одна дата (по умолчанию сегодня); от неё считаются «последние 7 дней» и «4 недели».
- **Показать отчёт** — пересчёт по выбранной дате.
- **Обновить данные** — загрузка данных со всех вкладок (январь, февраль, март) из Google Таблицы.
- **Метрика** — переключатель: Сумма / Количество / Средний чек (в сводке и на графиках по дням и неделям).
- **Фильтр по типам товаров** — исключение групп из отчёта (например, без Coffee makers).
- **Вкладки:** Итоги, 7 дней, По неделям, Каналы, Товары, **Аналитика** (тренд, сравнение периодов, выводы для решений).

Интерфейс рассчитан на мобильные устройства (mobile-first).

## Если доступ по ссылке закрыт

Если таблица не открыта для просмотра по ссылке, возможны варианты:

1. **Включить доступ по ссылке** (как выше) — тогда текущий скрипт будет работать без изменений.
2. **Google Sheets API** — настроить сервисный аккаунт в Google Cloud, выдать ему доступ к таблице и доработать скрипт (например, через `gspread`). При необходимости можно добавить такой вариант в проект.

## Деплой на GitHub и Railway

### 1. Репозиторий на GitHub

1. Создайте новый репозиторий на [github.com](https://github.com/new) (без README, без .gitignore).
2. Выполните в каталоге проекта (подставьте свой URL репозитория):

```powershell
cd D:\CursorProjects\online-sales-statistic
git remote add origin https://github.com/ВАШ_ЛОГИН/online-sales-statistic.git
git push -u origin production
```

Ветка **production** — для деплоя. Дальнейшие изменения: `git checkout production`, правки, `git add`, `git commit`, `git push origin production`.

### 2. Деплой на Railway

1. Зайдите на [railway.app](https://railway.app), войдите через GitHub.
2. **New Project** → **Deploy from GitHub repo** → выберите репозиторий **online-sales-statistic**, ветку **production**.
3. В настройках сервиса добавьте переменные окружения (Variables):
   - `SECRET_KEY` — длинная случайная строка (например, сгенерированная онлайн).
   - `ADMIN_USER` — логин входа (например, `admin`).
   - `ADMIN_PASSWORD` — пароль входа.
4. Railway сам соберёт проект (Nixpacks), установит зависимости и запустит по `railway.json`: `gunicorn --bind 0.0.0.0:$PORT app:app`.
5. В разделе **Settings** → **Networking** нажмите **Generate Domain** — получите публичный URL.

**Важно:** На Railway файловая система эфемерная. Кнопка «Обновить данные» подтянет CSV до перезапуска сервиса; после рестарта данные нужно обновить снова или настроить постоянное хранилище (Volume / внешнее хранилище).
